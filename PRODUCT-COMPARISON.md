# Chilling Place — полное сравнение продуктов и предложения

Дата исследования: **2 ноября 2026 года**. Проект: [Conditerili/chilling-place](https://github.com/Conditerili/chilling-place), Telegram: [@chillingplacebot](https://t.me/chillingplacebot).

Документ сохраняет все пункты сравнения из обсуждения: восемь продуктов, их оценку, 17 фич с примерами, приоритеты, три дизайна с изображениями, адаптацию и итоговое направление. Предложения ниже не означают, что они уже реализованы. Реализация и её проверки описываются отдельно в репозитории.

## Вывод и метод

Для Chilling Place я бы взял основу интерфейса у **stoic**, выбор эмоций — у **How We Feel**, а мягкую мотивацию возвращаться — у **Finch**. Это три самых полезных ориентира для проекта.

По README исходная версия — Telegram Mini App с дневником мыслей, короткими практиками и экраном «Сейчас». Аналоги подобраны именно для этих сценариев: дневник эмоций, быстрая поддержка в трудный момент и мягкая привычка возвращаться. В исходном репозитории также есть сад, музыка, библиотека и чекап; README описывает не все поздние дополнения.

Исследованы официальные описания и опубликованные экраны восьми продуктов. Оценки — авторская оценка пригодности для Chilling Place, а не рейтинг лечебной эффективности. Полные сценарии внутри установленных приложений не проходились. Дизайн оценивался по спокойствию интерфейса, удобству на телефоне, ясности действий и применимости к Telegram. Изображения — опубликованные экраны, некоторые относятся к более ранним версиям.

## 2. Выборка фич с примерами

В последнем столбце — предложения для Chilling Place: примеры адаптации, а не дословные экраны конкурентов.

| № | Фича | Где есть пример | Как применить у нас |
|---|---|---|---|
| 1 | **Быстрая отметка состояния** | Daylio: настроение → занятия | «Как ты сейчас?» → 5 состояний → необязательная заметка |
| 2 | **Уточнение эмоции** | How We Feel: цветовые группы и конкретные названия чувств | После «Мне тяжело» предложить «Тревожно / Грустно / Злюсь / Устал / Не понимаю» |
| 3 | **Объяснение эмоции** | How We Feel: определение выбранного чувства | Короткая подсказка, помогающая различить усталость и грусть |
| 4 | **Контекст состояния** | Daylio: занятия и пользовательские теги | Отметки «Работа / Учёба / Отношения / Сон / Без причины» |
| 5 | **Дневник по вопросам** | stoic: тематические guided journals | Вместо пустого поля: «Что произошло?» → «Что ты подумал?» → «Что тебе сейчас нужно?» |
| 6 | **Разбор тревожной мысли** | Clarity: Analyze Thought, работа с мыслительными искажениями | Отдельный пошаговый сценарий с вопросами и возможностью пропустить шаг |
| 7 | **Утренний и вечерний ритуал** | stoic: подготовка к дню и вечерняя рефлексия | Утром — одно намерение; вечером — одна трудность и один приятный момент |
| 8 | **Практика под текущее состояние** | How We Feel: стратегии работы с эмоциями | После отметки предложить 2–3 подходящих действия вместо всей библиотеки |
| 9 | **Выбор длительности** | Finch: упражнения и таймеры с разными длительностями | «Есть 1 минута / 3 минуты / 5 минут» |
| 10 | **Маленькие выполнимые цели** | Finch: вода, короткая прогулка, бытовые действия | Одна необязательная карточка «Маленький шаг на сегодня» |
| 11 | **Персонаж и развитие пространства** | Finch: питомец растёт через действия пользователя | Растение или уютный уголок, который постепенно меняется |
| 12 | **Календарь настроения** | Daylio: календарь и Year in Pixels | Цветные отметки дней, открывающие соответствующие записи |
| 13 | **Обзор повторений** | Daylio: связи настроения и занятий; MindDoc: графики | «В дни с прогулкой ты чаще отмечал спокойствие» — с количеством наблюдений |
| 14 | **Недельная рефлексия** | Reflection: недельные и месячные обзоры | «Что было важным? Что поддерживало? Что хочется изменить?» |
| 15 | **Голосовая запись** | Reflection: речь превращается в текст | Дополнительный способ вести дневник, когда трудно печатать |
| 16 | **Поддержка от близких** | Finch: Good Vibes; How We Feel: обмен состоянием с друзьями | Отправить выбранному человеку карточку «Мне сейчас нужна поддержка» |
| 17 | **Контроль над данными** | Reflection: экспорт; Clarity: локальное хранение по умолчанию | Сохранить существующий экспорт/импорт и сделать его понятнее пользователю |

Источники: [Daylio](https://daylio.net/), [How We Feel](https://apps.apple.com/us/app/how-we-feel/id1562706384), [stoic](https://www.getstoic.com/features), [Clarity](https://www.thinkwithclarity.com/), [Finch](https://finchcare.com/about-finch), [Reflection](https://www.reflection.app/), [MindDoc](https://www.minddoc.com/).

### Приоритеты ближайшего обновления

1. **Сохранять настроение и контекст.** В исходной версии, согласно README и экрану отметки, настроение не сохранялось. Это основа полезной истории.
2. **Предлагать практику после отметки состояния.** Простые правила подбора можно сделать без ИИ.
3. **Добавить короткие шаблоны дневника.** «Выговориться», «Разобрать ситуацию», «Заметить хорошее».
4. **Сделать календарь состояний и недельный обзор.**
5. **Сохранять ответ после практики:** «Стало легче / Без изменений / Сейчас не подходит». Дать быстрый доступ к тому, что пользователь сам отметил полезным.

Первые четыре пункта можно развивать на базе локальной модели хранения. Напоминания через Telegram потребуют работающего сервера бота; голосовая расшифровка, социальные функции и ИИ — отдельных решений по обработке данных. В исходной версии нет облачной синхронизации и подключённого ИИ. Не включать их автоматически только потому, что они есть у аналогов.

## 3. Три лучших дизайна из выборки

Рейтинг учитывает визуальный характер, ясность действий и возможность перенести решения в компактную Mini App. Ниже реальные опубликованные экраны, а не сгенерированные концепты.

### 1. stoic — лучший основной ориентир

![Главный экран stoic: приветствие и карточка ежедневной рефлексии](https://www.apple.com/newsroom/images/2025/09/apples-foundation-models-framework-unlocks-new-intelligent-app-experiences/article/Apple-Foundation-Models-framework-Stoic-home-screen_inline.jpg.large_2x.jpg)

[Источник изображения — Apple, сентябрь 2025](https://www.apple.com/newsroom/2025/09/apples-foundation-models-framework-unlocks-new-intelligent-app-experiences/).

**Почему выбрал:**

- Спокойная палитра и выразительная типографика.
- На главном экране понятен следующий шаг.
- Дневник воспринимается как личное пространство.
- Крупные карточки хорошо подходят для телефона.

**Что перенять:** структуру главного экрана, свободное пространство, одну заметную основную кнопку и короткие вопросы.

**Как адаптировать для нас:** сохранить у Chilling Place тёплый молочный фон и добавить шалфейный зелёный. Получится более мягкое настроение, подходящее названию.

### 2. How We Feel — лучший дизайн взаимодействия с эмоциями

![Выбор эмоции в How We Feel](https://marcbrackett.com/wp-content/uploads/2023/11/Mood-Meter-App-Img-02-1.jpg)

[Источник — страница соавтора How We Feel Марка Брэкетта](https://marcbrackett.com/how-we-feel-app-3/).

**Почему выбрал:**

- Цвет помогает ориентироваться в состояниях.
- Эмоции можно узнавать визуально, без длинной анкеты.
- Короткое определение помогает найти подходящее слово.
- Выбор состояния сам по себе становится осмысленным действием.

**Что перенять:** цветовое кодирование, уточнение эмоции и короткие объяснения.

**Как адаптировать для нас:** сначала показывать 5–6 крупных вариантов, затем раскрывать уточнения. Полная сетка из множества эмоций для первого экрана Chilling Place будет избыточной. Каждый цвет сопровождать текстом.

### 3. Finch — лучший дизайн ощущения заботы

![Главный экран Finch с персонажем и небольшими ежедневными целями](https://files.pi.fyi/cdn-cgi/image/quality%3D70%2Cformat%3Dwebp/users/cm71zplil004usi33lorwkpby/images/f98yr7fnpa8jl3dr6r6tp84u/original.jpg)

[Источник скриншота](https://www.pi.fyi/rec/cmah9bi0d03hyob3hqak9n3ra). [Официальное описание Finch](https://finchcare.com/about-finch).

**Почему выбрал:**

- Персонаж создаёт эмоциональную привязанность.
- Пастельные цвета и домашняя сцена поддерживают ощущение уюта.
- Маленькие действия получают заметный отклик.
- У продукта есть узнаваемый характер.

**Что перенять:** небольшой живой элемент, доброжелательные реакции и визуальные изменения после действий пользователя.

**Как адаптировать для нас:** выбрать растение у окна или маленькую комнату. Например, после практики загорается лампа, после записи появляется новый лист. Пропуск дня ничего не портит — это предложенный принцип нашей реализации.

## 4. Мой выбор для Chilling Place

Направление: **«уютное личное место»**.

| Элемент | Решение |
|---|---|
| Основа интерфейса | Простота и типографика stoic |
| Эмоции | Цвет и уточняющие варианты How We Feel |
| Характер | Уютная сцена по принципу Finch |
| Палитра | Молочный, шалфейный, тёплый серый; небольшие цветовые акценты эмоций |
| Главный экран | «Как ты сейчас?» → одно подходящее действие → маленький шаг |
| Навигация | Сохранить «Сейчас / Дневник / Практики» |
| Прогресс | Личная история и замеченные полезные действия |

Самое перспективное отличие — **короткий путь от состояния к действию**: открыть бота → назвать чувство → сделать что-то посильное → при желании сохранить мысль. Именно вокруг этого предлагается развивать продукт.
