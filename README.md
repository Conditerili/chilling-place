# CHILLING PLACE 🌿

Твоё место, чтобы выдохнуть. Бесплатный статический Telegram Mini App: короткая поддержка, дневник мыслей и небольшие практики.

**Открыть:** https://conditerili.github.io/chilling-place/

## Версия 7.0.1 — прежний дизайн Sakura Night

Полностью возвращены исходные фон, меню, розовое стекло, свечение и навигация версии до эксперимента. Новые состояния, календарь, шаблоны, карточки и кнопки оформлены в том же стиле. Все функции и сохранённые данные v7 остаются доступны.

## Функции версии 7

- Исходное оформление Sakura Night, розовые стеклянные элементы и навигация с иконками.
- Прогресс сада: цветы за записи и маленькие шаги, огонёк после практики. Пропуски дней не уменьшают прогресс.
- Шесть состояний с уточнением эмоции, описанием, контекстом и необязательной заметкой. Отметки сохраняются локально.
- Подбор коротких практик по последнему состоянию и фильтр «1 / 3 / 5 минут». Время ориентировочное; шаги проходят в своём темпе.
- Шесть шаблонов: разбор ситуации, свободная запись, хорошее, утро, вечер и неделя. Можно пропустить вопросы.
- Календарь состояний и записей, недельная сводка, наблюдения по контексту с числом дней и быстрый доступ к полезным практикам.
- История завершённых практик и обратная связь; повторная оценка обновляет тот же сеанс.
- Маленькие шаги сохраняются, одно и то же действие за день не начисляется повторно.
- Карточки поддержки для самостоятельной отправки близкому; дневник в них не добавляется.
- Необязательный голосовой ввод при поддержке браузера, с отдельным согласием перед распознаванием. В Telegram может быть доступна только диктовка клавиатуры.
- Импорт/экспорт теперь включает состояния, практики, маленькие шаги и типы дневников; старые записи продолжают читаться.

Полное исследование восьми аналогов, 17 фич и три дизайна с изображениями: [PRODUCT-COMPARISON.md](PRODUCT-COMPARISON.md). Соответствие всех предложений реализации и возврат: [EXPERIMENT-V7.md](EXPERIMENT-V7.md).

## Что работает без сервера

Вся Mini App размещается на GitHub Pages. Сборка и платные сервисы не нужны. Дневник работает локально в браузере/WebView: это не облачная синхронизация и не шифрование. Браузер и Telegram могут видеть разные истории. Не удаляйте данные сайта без экспорта. ИИ, напоминания и серверное хранение дневника **не подключены**.

При печатном вводе дневник не отправляется на наш сервер или ИИ; сторонней поведенческой аналитики нет. Статистика состояний считается на устройстве. Подключается официальный Telegram WebApp SDK; музыкальные файлы загружаются по действию пользователя из существующей музыкальной библиотеки и её источников. Голосовое распознавание браузера может использовать внешний сервис — перед запуском каждой записи запрашивается отдельное согласие. Состояния и обратная связь сохраняются локально. Время создания старых записей показывается в исходном виде, новые даты хранятся в ISO.

## Файлы и локальная проверка

- `index.html` — оболочка приложения.
- `styles.css` — оформление и темы.
- `app.js` — экраны и действия пользователя.
- `storage.js` — валидация, миграция, черновики, импорт и операции с данными.
- `content.js` — тексты практик.
- `wellbeing.js` — словарь состояний, шаблоны, подбор и локальные сводки.
- `cozy-ui.js` — уютный главный экран, календарь, карточки поддержки и голосовой ввод.
- `bot/server.js` — необязательный webhook Telegram.
- `tests/` — тесты данных и бота.

Для локальной разработки: Node.js 22+ для тестов, любой статический HTTP-сервер для сайта. Например, `python3 -m http.server 8080`, затем `http://localhost:8080`. Модули JavaScript не следует открывать через `file://`. Проверки: `npm test`. Установка npm-зависимостей не нужна.

После изменений меняйте версию в ссылках на CSS/JS и импортах модулей. Номер сборки отображается в настройках. Ссылка с `?v=5` остаётся рабочей: она не выбирает старую версию приложения.

## Необязательный сервер бота

GitHub Pages не запускает `bot/server.js`. Для обработки `/start`, `/help`, `/privacy`, `/settings` нужен постоянно доступный Node.js-сервис с HTTPS. Установка команд в BotFather сама по себе не запускает обработчик.

Переменные окружения на сервере:

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | Секретный токен BotFather. Не вставлять в исходники, клиентский JS, issues или чаты. |
| `WEBHOOK_SECRET` | Случайная секретная строка не короче 24 символов. |
| `APP_URL` | HTTPS-адрес Mini App; по умолчанию адрес выше. |
| `PORT` | Порт сервиса; по умолчанию 3000. |

Запуск: `npm run bot`. Проверка доступности: `GET /health`. Telegram webhook: `POST /telegram/webhook`. После размещения зарегистрируйте публичный HTTPS webhook через Telegram Bot API `setWebhook`, передав `url`, `secret_token=WEBHOOK_SECRET`, `allowed_updates=["message"]`. Выполняйте регистрацию из доверенного серверного окружения, не из кода страницы. Инструкция API: https://core.telegram.org/bots/api#setwebhook

Сервер проверяет секрет webhook, принимает только личные сообщения, не сохраняет и не выводит их тексты в лог. Повторные update_id отсеиваются в памяти до 24 часов (до 10 000 ID). Это **не** постоянная очередь: после перезапуска или при нескольких экземплярах возможна повторная доставка. Для производственного масштабирования нужна общая база идемпотентности; «ровно один раз» при сетевом сбое не гарантируется.

Сервер не читает дневник, не делает рассылки и не имитирует ИИ-консультанта. Его развёртывание, webhook и команды BotFather не выполняются автоматически при обновлении репозитория.

## Проверка перед выпуском

`npm test` проверяет валидацию, отсутствие дублей, старые данные, отказ хранилища, импорт, экспорт, очистку, команды и webhook. Дополнительно проверить в Telegram Android/iOS: клавиатуру, темы, кнопку назад, скачивание/импорт, повторное открытие и сохранность записей. Десктопная эмуляция не заменяет эти проверки. При недоступном скачивании в настройках можно показать JSON и скопировать его вручную.

## Границы продукта

Самоподдержка для взрослых, не диагностика, лечение или экстренная служба. Расширение упражнений требует профильной проверки содержания. Следующие независимые этапы: проверка с пользователями → размещение обработчика бота → согласованная серверная синхронизация → ограниченный ИИ с явным согласием и бюджетом. Не отправляйте дневники в облако автоматически при будущей миграции.
